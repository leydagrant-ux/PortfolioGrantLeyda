# Grant Leyda — portfolio

Mechanical engineering portfolio. Static site, no build step, no dependencies at runtime.

**Live:** https://leydagrant-ux.github.io/portfolio/

## Running it locally

```bash
python -m http.server 8080
```

Then open <http://localhost:8080/>. It must be served over HTTP rather than opened as a
`file://` path — the pages use ES modules and `fetch` for the 3D models, and both are
blocked on the file protocol.

## Layout

```
index.html              Home — hero, metrics, project cards, capabilities, about
projects/
  rotator.html          Senior capstone case study (the centrepiece)
  bankroll.html         Software project case study
  _TEMPLATE.html        Starting point for a new project page
data/projects.js        The project manifest — cards and pager render from this
css/site.css            Design tokens and every component
js/
  main.js               Theme, nav, scroll reveals, count-ups, card tilt
  project-cards.js      Renders the card grid and the prev/next pager
  viewer3d.js           three.js STL viewers + the wireframe hero background
  pin-study.js          The interactive pin sizing calculator
  lightbox.js           Image lightbox and the compare slider
vendor/three/           three.js r185, vendored (MIT)
assets/                 Generated — see below
tools/build_assets.py   Asset pipeline
```

## Assets

Everything in `assets/img`, `assets/models` and `assets/video` is generated by
`tools/build_assets.py` and committed. Regenerate with:

```bash
python tools/build_assets.py
```

It reads from the original SolidWorks exports and PowerPoint decks on Grant's machine,
plus anything dropped into `assets/raw/`. Sources that aren't present are reported and
skipped, so the script still works on a machine that only has `assets/raw/`.

Requires Pillow (`pip install pillow`).

## Adding a project

See [ADDING_A_PROJECT.md](ADDING_A_PROJECT.md). Short version: drop media in
`assets/raw/`, run the build, copy `_TEMPLATE.html`, add one object to `data/projects.js`.

## Notes for future edits

**The pin study numbers are load-bearing.** `js/pin-study.js` reproduces the hand
calculations from the capstone's Critical Component Analysis report exactly. If you touch
that file, load any page carrying the study with `?selftest=1` and check the console — it
asserts all three reference diameters against the report values.

```
projects/rotator.html?selftest=1
```

**Accessibility is not optional here.** Every animation is gated behind
`prefers-reduced-motion`, the lightbox traps focus and returns it, and the 3D canvases are
`aria-hidden` with their dimensions exposed as text. Keep that true.

**The STLs are part-local.** SolidWorks exported each one with its minimum corner at the
origin, so they cannot be composed into a full assembly in the browser — the viewer
recentres each part individually. To show the whole machine in 3D you would need a single
STL exported from the assembly with "Save all components in a single file" checked.
